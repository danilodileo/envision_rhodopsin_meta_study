# ENVISION — Rhodopsin metatranscriptomic study

Analysis code and figures for a metatranscriptomic study of microbial rhodopsin
expression in a genomic context, based on samples collected off the coast of
northeast Spain (ENVISION dataset). This repository accompanies the
manuscript currently in preparation / under review.

## Repository structure

```
.
├── scripts/    Quarto (.qmd) analysis scripts — see "Scripts" below
├── figures/    Final manuscript figures (PDF), regenerated by the scripts
├── tables/     Supplementary/result tables (CSV), regenerated by the scripts
└── README.md
```

## Data availability

The intermediate summary tables and metadata used as input to these scripts
are **not included** in this repository: the manuscript is not yet published,
and the underlying tables are kept private until then. The analysis **code**
is fully open here so reviewers and readers can inspect exactly how each
figure was produced.

If you need access to the input tables (e.g. for peer review), please contact
**Danilo Di Leo** — danilo.dileo@hotmail.com.

## Requirements

- **R** ≥ 4.5 and **[Quarto](https://quarto.org/)** ≥ 1.3 (developed with R 4.5.2 / Quarto 1.3.450)
- Internet access when rendering: some chunks query live services (NOAA

  / `KEGGREST`, `bitr_kegg()`)

## Scripts

All scripts are self-contained Quarto documents (`format: html`) with
`cache: true` set globally, so repeated renders reuse unchanged chunks. Render
any of them with:

```bash
quarto render scripts/<script-name>.qmd
```

Each script expects to be run from a working directory containing the
(private) `data/` and `summary_tables/` folders described above, and writes
its figures to a local `figures/` subfolder.

| Script | What it does |
|---|---|
| `prepare_tables.qmd` | Data-preparation pipeline. Reads the raw taxonomy, KEGG/eggNOG annotation and count outputs and writes the intermediate summary tables (`summary_tables/*.tsv.gz`) and cleaned metadata (`data/envision_metadata.tsv.gz`) used by every other script. **Cannot be re-run without the raw inputs**, which are not distributed here; included for pipeline transparency. |
| `Overall_community_composition.qmd` | Site/season overview: sampling map with an Atlantic/Europe locator inset, environmental variable time series, mapping-rate statistics, rhodopsin-expressing genome overlap, taxonomic composition, NMDS ordination of community structure, and family-level rhodopsin expression heatmaps against environmental variables. Produces **Figure 1**, **Figure 2**, **Figure S1**, **Figure S2**, **Figure S3**. |
| `fine-scale-analysis.qmd` | Genome-resolved analysis of the top-30 rhodopsin-expressing genomes: multi-track ComplexHeatmap of genome abundance/rhodopsin expression, Spearman correlations between rhodopsin and whole-genome transcription (per genome and per family), and family-specific time-series of rhodopsin expression vs. environmental variables (Poseidoniaceae, Puniceispirillaceae, Porticoccaceae) and KO-level bubble plots (Thalassarchaeaceae, Pelagibacteraceae, Porticoccaceae). Produces **Figure 3**, **Figure 4**, **Figure S4**, **Figure S5**, **Figure S6**, **Figure S7**, **Figure S8**, **Figure S9**. |
| `untargeted_analysis.qmd` | KEGG pathway/module enrichment analysis (family- and genome-level GSEA), motility/pili/transporter KO correlation heatmaps, and rhodopsin-transporter co-expression in *Pelagibacter* genomes. Produces **Figure 5**, **Figure S10**. |

## Tables

| Table | Script | Chunk | Contents |
|---|---|---|---|
| `tables/supplementary-table-1.csv` | `Overall_community_composition.qmd` | `summary-genome-overview` | Number of taxa (genomes, species, genus, ..., domain) in the full dataset, the active transcriptome, rhodopsin-encoding genomes, and the actively expressed rhodopsin group. |
| `tables/supplementary-table-2.csv` | `Overall_community_composition.qmd` | `NMDS_genome-level-bray-curtis` | PERMANOVA (season + site) for the genome-level NMDS of all genomes. |
| `tables/supplementary-table-3.csv` | `Overall_community_composition.qmd` | `NMDS_genome-level-bray-curtis` | PERMANOVA (season + site) for the genome-level NMDS of rhodopsin-expressing genomes. |
| `tables/supplementary-table-4.csv` | `Overall_community_composition.qmd` | `NMDS_ENVFIT` | PERMANOVA (environmental variables) for the NMDS of rhodopsin genes. |
| `tables/genome-stats-table.csv.gz` | `Overall_community_composition.qmd` | `genome-stats-table` | One row per genome that attracted reads (10,615 genomes), with full GTDB taxonomy, assembly size, CheckM completeness/contamination, and size corrected for completeness; the top 30 rhodopsin-expressing genomes are sorted to the top. **Coverage gap**: CheckM completeness/contamination is only available for NCBI/GTDB reference genomes — the locally assembled/binned genomes (`metabat2.*`, `concoct.*`, 348 in the full catalog, one of which is in the top 30) have no CheckM run recorded and are left as `NA`, flagged in the `qc_source` column. |
